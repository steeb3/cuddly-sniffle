# cuddly-sniffle

Welcome! This repository contains a **Budget Tracker** app to help you manage your spending!

## Budget Tracker App

A simple, beautiful budget tracking application that runs in your web browser.

### How to Use

1. **Open the app**: Double-click `index.html` to open it in your browser
2. **Add expenses**: Fill out the form with description, amount, category, and date
3. **Track spending**: See your total spending and monthly breakdown
4. **View categories**: See which categories you spend most on
5. **Manage expenses**: Delete individual expenses or clear all

### Features

- Track expenses with 7 different categories (Food, Entertainment, Bills, Shopping, Transport, Health, Other)
- See total spending and current month totals
- Visual category breakdown with progress bars
- Your data is saved automatically in your browser
- Works on desktop and mobile
- No internet required - runs completely offline!

For detailed instructions, see [HOW_TO_USE.md](HOW_TO_USE.md)
